# ZZP Rekentools

Small static Dutch-language site with two calculators for freelancers (zzp'ers):

- `btw-calculator.html` + `btw.js`: converts amounts incl./excl. BTW at 21%, 9% or 0%.
- `uurtarief-calculator.html` + `uurtarief.js`: indicative hourly rate from desired net income, costs, billable hours, weeks off and a tax/pension buffer.
- `index.html`, `over.html`, `style.css`: landing page, disclaimer and styling.

Live: https://leilastar.github.io/zzp-tools-nl/

Plain HTML, CSS and JavaScript. No build step, no trackers, no external requests. Deployed with GitHub Pages from `main`, root folder.

Results are indicative and are not tax advice.
